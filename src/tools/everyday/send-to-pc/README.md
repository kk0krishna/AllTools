# Send to PC & Cross-Device Clipboard Bridge

**Category:** Everyday  
**Route:** `/tools/everyday/send-to-pc`  
**Description:** Instantly send photos, camera scans, documents, passwords, and clipboard notes between your phone and PC wirelessly using peer-to-peer WebRTC DataChannels.

## Combined Inspiration
- **vFlat:** High-speed camera scan-to-PC workflow, QR code pairing, and instant image transfer.
- **CopyPaste.me:** Frictionless, encrypted clipboard bridge, sensitive password transfer with "Burn on Copy" self-destruct, and direct link opening.

## Features
- **Zero Software Installation:** Works directly within any browser (Chrome, Safari, Firefox, Edge).
- **Fast QR Pairing:** Point phone camera at PC screen to pair instantly in seconds.
- **PIN Code Fallback:** 6-digit numeric PIN for devices without working cameras.
- **Camera Scanner:** Snap physical documents, books, or papers directly from phone camera.
- **Sensitive Password & Secret Bridge (CopyPaste.me):** Send passwords with optional "Burn after 1 copy" self-destruct.
- **Auto-Copy to Clipboard:** Incoming text/passwords can be copied automatically to system clipboard.
- **Link Sharing:** Direct "Open in New Tab" for web links and URLs.
- **Direct P2P Encrypted:** Transferred directly over local network / WebRTC without server storage.
- **Batch Export:** Download all received files as a single ZIP archive using JSZip.
- **Bidirectional Console:** Send files, text, passwords, and links from PC to phone, or phone to PC.
